# 第三阶段：维护成本与生成器迁移验证

核验日期：2026-10-22。用户已决定继续使用当前 MkDocs/Material，暂不迁移。两套实验保留供以后参考，不列入当前实施计划。两个候选都进行了本机实际构建，尚无一个达到直接替换生产的条件。实验产物仅留在本机，没有上传或部署。

## 已落地的维护改动

- `shared/blog.json` 统一站点地址、仓库、栏目顺序/名称/标签、排除路径、公开状态、RSS/Dataview 范围和日期时区。MkDocs 继承它，Python 工具读取同一来源；写作室使用生成副本，继续支持独立打包。
- `shared/diagrams/` 是 Mermaid 的唯一编辑来源，博客直接读取，写作室保留同步副本及原资源 URL。`scripts/sync_shared.py --check` 和现有 Python 测试阻止副本漂移；不改 CI 即可进入已有质量门禁。
- 写作室 `article-index.ts` 共用网页/MCP 的文章缓存与索引；`draft-store.ts` 共用用户归属查询、版本快照和文件编号。权限入口、请求响应、恢复与发布语义保留，未引入数据库迁移。
- 排除路径校验与 MkDocs 对齐：如单段 `superpowers` 会匹配任意层级，避免接受最终不会构建的文章；非字符串输入仍返回无效路径。

维护命令与边界见 [共享规则说明](../shared/README.md) 和 [写作室说明](../publisher/README.md)。没有移动文章、重命名公开路径或清理历史文件。

## 候选方案比较

| 维度 | Zensical 0.0.71 | Quartz 5 固定提交 |
| --- | --- | --- |
| 本机实际结果 | 原配置严格失败；桥接严格通过 | 原文与最小适配两组均构建成功 |
| 公开状态 | 直接构建漏排真实草稿；桥接过滤正确 | 默认不识别 `status: draft/private`；导出先行过滤 |
| 旧路径 | 桥接保留全部 254 条栏目路径 | 254 个 slug 改变，257 处目录式落盘目标不同 |
| Dataview | 桥接保留 28 个静态任务块 | 现有静态转换可处理 28 页 |
| RSS | 桥接保留 180 条且主要字段一致 | 本次默认仅 10 条生成目录页，日期语义不符 |
| 中文搜索 | “英语”得到 432 个章节命中 | “信息茧房”首条正确命中 |
| 主要剩余成本 | 去除 MkDocs 桥接依赖、移植自定义主题和前端交互 | URL 兼容、状态与日期/RSS规则、主题/系列重做、重复 H1 |

路径数不是文章数，搜索命中数也不是文章数。Quartz 的落盘差异不等于已经证明线上 404；实际托管端的路径重写尚未验证。两套实验的耗时受环境和缓存影响，本次不作性能排名。

详细证据、固定版本、官方来源、完整复现命令及未验收项：

- [Zensical 实验](zensical/README.md)
- [Quartz 实验](quartz/README.md)

若要进入正式迁移，先要求同一公开内容集合、旧 URL 和锚点兼容、私有内容在页面/搜索/RSS中均排除、订阅 GUID/日期稳定、当前页面设计及数学/图表通过浏览器验收。只有构建成功不满足迁移条件。
