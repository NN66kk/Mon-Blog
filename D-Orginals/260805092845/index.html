    Windows 卸载神器 BCU：开源免费，还能批量清理软件残留

    Mon 的个人花园 正在计算 · 阅读模式

    今天给大家推荐一个 Windows 端卸载软件的神器。

    之前大家应该都听过 Geek Uninstaller。它在卸载软件以后，可以继续扫描软件留下的文件、文件夹和注册表项目，通常会比 Windows 自带的卸载功能清理得更加干净。

    不过 Geek 并不是开源软件，而且免费版的功能相对基础，批量卸载等功能需要使用付费的专业版本。它的界面虽然简单，但整体设计也稍微有些年代感。

    今天给大家推荐另一款可以作为 Geek 平替的开源项目，名字叫做 Bulk Crap Uninstaller，简称 BCU 或者 BCUninstaller。

    项目链接我会放在文末。

    BCU 是什么¶

    BCU 是一款专门用于 Windows 系统的软件卸载工具。

    它最大的特点，是可以批量卸载大量软件，并且尽可能减少人工操作。除了普通的软件卸载，它还可以扫描卸载残留、识别失效的卸载项、强制移除损坏的软件，以及管理一些不会正常显示在 Windows 软件列表中的程序。

    BCU 采用 Apache 2.0 开源许可证，个人和商业环境都可以免费使用。

    它的名字 Bulk Crap Uninstaller 直译过来，大概就是“批量垃圾软件卸载器”。名字听起来比较直接，但也准确概括了它的主要用途：一次性清理电脑中大量不再需要的软件。

    为什么推荐 BCU¶

    1. 卸载以后继续扫描残留¶

    使用 Windows 自带的卸载功能时，系统通常只是运行软件官方提供的卸载程序。

    但很多软件卸载以后，仍然会在电脑中留下：

    • 安装目录和空文件夹；

    • 用户配置文件；

    • 缓存和日志文件；

    • 注册表项目；

    • 已经失效的卸载信息。

    BCU 会优先调用软件自己的卸载程序。卸载结束以后，再扫描可能遗留的文件、文件夹和注册表项目，让用户决定是否继续清理。

    需要注意的是，残留扫描并不是绝对准确的。删除之前最好检查一下扫描结果，不要看到所有项目就直接全部勾选。

    2. 支持批量卸载软件¶

    这是 BCU 相比很多普通卸载工具最明显的优势。

    你可以一次选择多个软件，然后让 BCU 按照顺序自动执行卸载。对于支持静默卸载的软件，它还可以减少安装向导和确认窗口的数量。

    如果刚买了一台新电脑，系统里预装了大量用不到的软件，或者电脑里积累了很多旧工具、测试软件和游戏组件，使用批量卸载会节省不少时间。

    BCU 还会尽量避免同时卸载存在冲突的软件，降低多个卸载程序互相干扰的概率。

    3. 能识别更多类型的软件¶

    BCU 显示的不只是 Windows“已安装的应用”列表中的普通软件。

    它还可以识别和管理：

    • 普通桌面软件；

    • 隐藏或者受保护的卸载项；

    • 卸载程序损坏的软件；

    • 部分便携软件；

    • Microsoft Store 应用；

    • Steam 游戏和应用；

    • Chocolatey 安装的软件包；

    • Windows 系统功能；

    • Windows 更新。

    这些项目会统一显示在 BCU 的软件列表中，可以进行搜索、筛选、排序和批量处理。

    对于经常安装开发环境、命令行工具、游戏或者各种测试软件的人来说，这项功能非常实用。

    4. 支持强制卸载¶

    有些软件明明还占着文件夹和注册表项目，但它自己的卸载程序已经损坏，点击卸载只会报错。

    这种情况下，可以使用 BCU 的强制卸载功能。

    强制卸载会绕过软件原来的卸载程序，直接查找与该软件相关的文件和注册表内容。它适合处理卸载程序丢失、安装记录损坏或者卸载过程反复报错的软件。

    不过这项功能的风险也比普通卸载更高。只要软件自己的卸载程序还能正常使用，就应该优先执行正常卸载。

    5. 筛选功能非常丰富¶

    第一次打开 BCU 时，可能会觉得它的界面比 Geek 复杂，因为主界面会显示大量软件信息。

    但这也是它适合高级用户的原因。

    BCU 可以按照软件名称、发布者、安装位置、安装时间、软件大小和卸载方式进行筛选，还可以使用正则表达式创建自定义过滤规则。

    软件列表中也会通过颜色和标记提示不同类型的项目，例如：

    • 已验证的软件；

    • 没有有效卸载程序的软件；

    • 疑似残留的软件；

    • Windows 系统组件；

    • Microsoft Store 应用；

    • 未注册的应用程序。

    对于不熟悉的项目，可以先查看发布者、安装目录和数字签名，再决定是否删除。

    应该下载哪个版本¶

    BCU 通常提供三个版本。

    Setup 安装版¶

    安装版会像普通软件一样安装到 Windows 中，并创建开始菜单入口和卸载信息。

    如果电脑缺少程序需要的 .NET 运行环境，安装程序也可以协助完成安装。

    对于大多数普通用户，我更推荐这个版本。安装完成以后，可以直接在开始菜单中搜索：

    Bulk Crap Uninstaller

    或者：

    BCUninstaller

    Portable 便携版¶

    便携版不需要安装，解压以后直接运行文件夹中的：

    BCUninstaller.exe

    它已经包含需要的运行环境，所以文件体积会相对大一些。

    需要注意，运行便携版的 EXE 文件并不等于把软件安装到了电脑里。Windows 开始菜单中可能不会出现它，系统的“已安装的应用”列表中也未必能够找到它。

    下次使用时，需要重新进入解压后的文件夹，运行 BCUninstaller.exe。

    为了方便，可以右键这个文件，选择：

    发送到 → 桌面快捷方式

    这样以后就可以直接从桌面打开。

    net 便携版¶

    这个版本同样不需要安装，但是电脑中必须已经存在对应的 .NET 桌面运行环境。

    它的体积比完整便携版更小，适合已经安装相关运行环境的用户。

    如果不清楚电脑有没有对应的 .NET 环境，直接选择 Setup 安装版或者完整 Portable 便携版即可。BCU 6.x 版本官方支持 Windows 10 及以上系统，并使用 .NET 8 桌面运行环境；完整便携版不要求系统提前安装该运行环境。

    BCU 的基本使用方法¶

    第一步：打开软件并扫描列表¶

    第一次启动时，BCU 会读取电脑中的软件信息。

    电脑里安装的软件越多，第一次加载需要的时间就可能越长。等待扫描完成以后，就能在主界面看到软件列表。

    如果需要删除系统级软件，可以右键 BCU，选择“以管理员身份运行”。

    第二步：找到需要卸载的软件¶

    可以直接在搜索框中输入软件名称，也可以根据发布者、安装时间和软件大小进行排序。

    选中一个软件后，界面中通常会显示它的安装路径、卸载命令、注册表位置和数字签名等信息。

    卸载之前建议先确认软件名称和发布者，尤其不要随意删除自己不认识的驱动程序和系统组件。

    第三步：执行卸载¶

    选中需要删除的软件，然后点击卸载按钮。

    BCU 会让你选择卸载方式。普通用户使用默认选项即可，不需要一开始就开启强制卸载或者过于激进的自动清理功能。

    如果一次选择了多个软件，BCU 会创建批量卸载任务，并依次运行这些软件的卸载程序。

    第四步：创建还原点¶

    在批量卸载或者清理大量残留之前，建议允许 BCU 创建系统还原点。

    如果后续发现误删了重要组件，可以尝试通过系统还原恢复电脑状态。

    虽然创建还原点会多花一点时间，但在集中清理软件时非常有必要。

    第五步：扫描卸载残留¶

    正常卸载结束以后，BCU 会询问是否查找残留项目。

    扫描结果一般会根据可信程度进行分类。可信程度较高的项目通常与刚刚卸载的软件名称、安装目录或者注册表位置直接相关。

    建议优先删除明确属于该软件的内容。对于路径模糊、名称不明确或者可能被多个软件共用的项目，可以暂时保留。

    哪些东西不要随便卸载¶

    BCU 的检测能力比较强，但能够显示出来，不代表所有项目都应该删除。

    下面这些内容需要格外谨慎：

    • 显卡、声卡、网卡和芯片组驱动；

    • Microsoft Visual C++ Redistributable；

    • .NET Runtime 和 .NET SDK；

    • Java 运行环境；

    • Python、Node.js 和其他开发环境；

    • 软件共用的更新组件；

    • Windows 系统功能；

    • 名称中包含 Driver、Runtime、Framework、Service 的程序。

    例如，电脑里可能同时存在多个年份和架构的 Visual C++ 运行库。它们看起来比较重复，但不同软件可能依赖不同版本，不能简单地只保留最新版本。

    遇到不认识的项目，最好先搜索它的名称和发布者，再决定是否卸载。

    总结¶

    BCU 并不是那种打开以后只有一个卸载按钮的极简工具，它更像是一套完整的 Windows 软件管理和清理工具。

    它既能完成普通的软件卸载，也能批量处理大量程序，扫描卸载残留，识别损坏的卸载项，并管理 Microsoft Store 应用、Steam 游戏和 Windows 功能。

    虽然第一次打开时界面可能稍微复杂，但熟悉基本操作以后，日常真正需要使用的功能其实只有几个：

    搜索软件 → 选择卸载 → 扫描残留 → 确认删除

    对于喜欢开源软件，或者经常折腾 Windows、安装各种开发工具和测试程序的人来说，BCU 值得长期保留在电脑里。
