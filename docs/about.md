# 关于我

我来自河南，现在在北京读研。

写作是我整理思考的方式。这座数字花园不追求标准答案，更像一份持续修订的个人记录：技术与工具是现实问题的解法，山野与训练让我重新感受身体，心理学则帮助我理解人与关系。

我喜欢徒步和自由搏击，也长期关注人工智能。比起热闹，我更享受独处；比起模糊的承诺，我更看重效率、边界和独立判断。

我不擅长把生活写成一条笔直的上升曲线。拖延、困惑和反复都真实存在，但我仍愿意保持清醒，持续前行。

> 永远不要自怜，永远不要嫉妒。
> ——查理·芒格

如果你也在认真解决问题、重建生活秩序，或只是想看看另一个人如何理解世界，欢迎沿着这里的文章慢慢逛。
