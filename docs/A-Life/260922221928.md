# 西南灵徒步记忆

## 1. 一场 18 公里的徒步

前几天和三位朋友一起去了张家口涿鹿县的西南灵徒步，我们一行四人报了个旅行团不到七点就出发了，全程大约 18～19 公里，累计爬升 1200～1400 米，整体算是中等强度。

对我来说，这次徒步的强度其实不算大。一路走下来并没有特别疲惫，大部分时间状态都还不错。

### 1.1 靠意志力走完全程的人

这次徒步真正让我印象深刻的，反而是同行的一位朋友。

他平时很少徒步，刚走两公里就已经累得够呛。当时看他的状态，我甚至觉得他可能坚持不到最后，路上也劝过他好几次，要不就提前下撤（中间还吐了一次）。

但他的态度非常坚决：一定要走完。

后面的路对他来说明显越来越难，到最后整个人几乎都要散架了，但还是硬生生靠着意志力把全程走了下来。

体力好的人走完一条路线并不稀奇，一个平时很少徒步、前几公里就已经很累的人，依然坚持走完全程，反而更让我佩服。

有时候，人的体力确实存在极限，但意志力往往能把这个极限再往后推一点。

### 1.2 夏秋交界的西南灵

这次西南灵的风景也相当不错。

九月的山里正处于夏秋交接的时候，它既没有完全褪去夏天的绿色，也没有彻底进入深秋。

一路上能看到很丰富的颜色。有些树依然是青绿色，有些已经开始泛黄，还有一些叶子已经变成了红色。不同颜色交织在山坡上，一片青、一片黄、一片红，层层叠叠。

它不像盛夏那样满眼苍翠，也不像深秋那样漫山红黄，反而因为处在季节交替的过程中，多了一些变化。

这种“不完全属于某一个季节”的状态，也有一种独特的味道。

## 2. 风景与记录

### 2.1 手机与相机

这次徒步还有一个很直接的感受：手机拍照和相机之间，确实还是有差距的。

一路上看到很多景色的时候，都有一种想认真记录下来的冲动，也因此第一次比较强烈地想拥有一台真正的相机。

不过仔细想想，即便是再好的相机，能够记录下来的依然只是眼前景色的一部分。

真正站在山里时，眼睛看到的是连绵的山脉、天空、树林和远处的地平线，耳边还有风声，身体能够感受到温度和空气。所有这些东西共同构成的现场感，很难被一张照片完整记录下来。

### 2.2 有些风景只能亲眼去看

照片能够留下一个瞬间，但人在现场感受到的，是一个完整的世界。

很多时候，我们看到一处漂亮的风景，第一反应都是拿出手机拍下来。但真正回头看照片的时候，又总觉得和当时亲眼看到的差了很多。

或许并不是设备不够好，而是大自然本身就很难被压缩进一块小小的屏幕。

再好的相机，也很难完全拍出眼睛看到的那种震撼，更难记录身处其中时感受到的自然的力量。

所以旅行和徒步真正吸引人的地方，大概也正在这里：有些东西可以被记录，而有些东西只能亲自去看、去走、去感受。

## 3. 身体给我的提醒

### 3.1 当天不累，第二天浑身疼

徒步当天结束以后，我其实没有觉得特别累。

返程坐地铁的时候，整个人甚至还挺轻松。当时还觉得自己的体能似乎保持得不错，18 公里走下来也没什么感觉。

结果第二天睡醒之后，身体立刻给出了完全不同的答案。

浑身肌肉酸痛，下楼梯都费劲，这种酸痛持续了两天左右才基本恢复。

### 3.2 锻炼还是贵在坚持

仔细想想，原因其实很简单：前段时间很久没有系统锻炼，也很长时间没有去健身房了。

即使以前有一定的运动基础，停下来一段时间之后，身体依然会慢慢失去对这种运动强度的适应。

偶尔一次高强度运动，或许可以靠原来的体能和意志力撑下来，但身体的反馈不会骗人。

这次徒步也算给自己提了个醒：锻炼最重要的还是持续。

与其隔很长时间突然进行一次高强度运动，把自己折腾得浑身酸痛，不如把运动真正变成生活的一部分，让身体始终保持在一个相对稳定的状态。

## 4. 写在最后

回头来看，这次西南灵徒步其实没有什么惊心动魄的故事。

一行人，十八九公里的山路，一千多米的爬升，从山脚一路走到山上，再一步一步走回来。

但真正留在记忆里的，往往就是这些很具体的瞬间：

是一个已经累得不行的人，仍然坚持把最后的路走完；

是夏秋交界时，一座山同时出现青、黄、红三种颜色；

是站在山上拿出手机拍照，却发现镜头怎么也装不下眼前的景色；

也是第二天起床时浑身酸痛，突然意识到自己确实该重新开始锻炼了。

徒步大概就是这样。

走出去的时候，看到的是山川和风景；走回来以后，留下来的，还有一些关于朋友、关于自己，也关于生活的感受。
