# 写作室管理平台交付记录

日期：2026-09-22。范围：在现有私人写作室上增加文章、草稿、图片、历史、回收站和备份管理。

## 交付内容

- 管理中心 `/`，六个模块共用搜索、筛选、操作反馈和手机导航；原写作编辑器移到 `/write`，保存后 URL 保留草稿 ID。
- 已发布文章从 GitHub 同步，按 SHA 缓存真实标题、标签、摘要和日期；支持修改、删除、查看最近 30 条 Git 历史、提取旧版为草稿。
- 私有草稿支持复制、选择备份、批量回收、恢复和 Markdown 导入；每次保存保留历史版本，恢复旧版生成新的修订。
- 图片库展示私有图片及博客图片；可上传、插入、下载和复制引用，显示使用该图的草稿，归档后仍可恢复。
- 文章删除前将完整 Markdown 保存到数据库并要求输入标题确认；恢复回原路径，遇到同路径内容或并发修改会停止，绝不强制覆盖。
- 发布记录区分发布、删除和恢复，跟踪提交、构建和实际在线状态。取消构建可由后续包含该提交的成功部署完成。
- 标签、摘要、高级 YAML 和历史入口在手机上可达；延续现有深蓝侧栏、浅色纸面和字体风格。

## 数据和权限

新增迁移：`drizzle/0002_mushy_starhawk.sql`。增加 `draft_versions`、`article_cache`、`article_trash`、`media_entries`；为原表增加兼容字段，没有删除数据的迁移语句。

所有管理接口沿用登录隔离和写入来源校验。GitHub token 留在服务端加密存储，不出现在备份和错误文本中。仓库写入使用文章 SHA 检查和非强制分支推进。删除仅针对支持栏目的文章路径，不触碰重定向文章、工作流或其他文件。本文档不包含任何凭据。

图片归档不是物理删除；草稿移入回收站不会删除公开文章。已发布文章的恢复副本保留在数据库中；草稿 ZIP 的范围在下载界面说明，不声称备份所有 Git 历史或整个网站。
